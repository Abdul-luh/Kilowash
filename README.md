# Kilowash

Solar-powered automated laundry service for student hostels. Book a 30-minute wash slot online, get a PIN, unlock the machine instantly — no queues, no light issues, no wahala.

## What it is

Kilowash is a landing page + waitlist for a smart hostel laundry system built on ESP32-controlled washing machines. Students book and pay online, receive a keypad PIN, and the machine auto-releases after a 10-minute unload buffer.

## Stack

- React + TypeScript + Vite
- Tailwind CSS (utility-first styling)
- Neumorphic / claymorphic UI design

## Sections

- **Hero** — live bay status snapshot, CTAs, key metrics
- **Ticker** — scrolling trust signals
- **How It Works** — 3-step booking flow
- **Pricing** — Standard (₦1,500), Heavy (₦1,800), Delicate (₦1,500)
- **FAQ** — common questions
- **Waitlist** — early access sign-up
- **Contact** — reach the team
